# 資料保存與題庫

## 個人資料

localStorage key：`kanjitest:data:v1`。資料版本為 1；沒有登入、伺服器同步或後端個人資料庫。不同瀏覽器、裝置及網站 origin 各自保存；預覽站和正式站的個人資料也分開。

| 欄位 | 內容 |
| --- | --- |
| `version` | 固定 1 |
| `customWords` | 使用 `custom:` UUID 的單字、讀音與中文解釋 |
| `bookmarkIds` | 內建／自訂單字 ID，不複製整份詞條 |
| `wordStats` | 各 ID 的正確與錯誤累計次數 |
| `round` | 分類、原設定題數、錯題複習標記、單字快照、進度與本輪結果；沒有輪次時為 null |

編輯自訂字保留 ID、書籤及統計；尚未作答的輪次快照更新，已答快照保留。刪除自訂字移除其書籤；本輪已保存的字與結果仍可查看，不能再替已刪除字新增書籤。

LocalRepository 先驗證下一份狀態，再寫 localStorage，成功後才更新記憶體。讀取失敗時保留原始內容、停止覆寫；仍可在目前分頁暫存內建測驗，但重新整理不能保留這份暫存。

## 備份與舊版遷移

齒輪內提供 JSON 匯出／合併匯入。匯入檔上限 2 MiB，內容需通過資料與來源 ID 驗證。相同自訂 ID 而內容衝突時拒絕合併；沒有自動猜測哪份較新。

書籤去重，自訂字依 ID 合併；統計正確／錯誤計數各取最大值，重複匯入不累加。有輪次時保留目前輪次，否則還原備份輪次。這是備份快照合併，不能精確合併兩個裝置各自新增的全部作答。

舊 `history` 僅在缺少累計統計時建立初值，之後不保存或匯出；不追回已丟失的更早歷史。已移除 `autoBookmarkWrong` 設定，舊備份不恢復自動收藏。舊手動下一題輪次改為自動前進，未答純假名與重複字形移出；已答快照保持當時內容及判分。

舊 Go／PostgreSQL 的帳號與私人資料沒有發布到新站，也不會自動匯入瀏覽器。

## 抽題演算法

先依分類取得候選，以 NFKC 字形去重；純假名不出題。每個內建字形合計所有來源 ID 的統計，令正確 c 次、錯誤 m 次：

```text
p = (m + 1) / (c + m + 2)
w = 0.25 + 1.75 × p
```

每次取剩餘字權重總和 W，以均勻隨機數 r∈[0,W) 選中累積權重所在的字，移出候選池，重複至題數或候選用完。屬於依權重無重複抽題。未答過的權重 1.125；答 10 次錯 8 次的權重 1.5625，錯 2 次為 0.6875，前者單次機率約為後者 2.27 倍。這不是整輪出現率的固定倍數。

0.25 底值保留熟悉單字的抽選機會；加 1／加 2 的平滑避免少量作答導致極端機率。錯題重練仍計入累計統計，再來一輪回到原設定題數及分類。

## 題庫更新

保留原始 ID，不直接以新的匯入結果覆寫封存來源。先用 `tools/import-tomoshi.py dictionary.db candidates.js` 產生候選，再按官方 XML 的字形／讀音／義項限制核對。重建既有校正版：

```sh
python tools/audit-vocabulary.py JMdict_e.gz dictionary.db audit-output
```

保留官方 XML 日期、checksum 與逐筆 CSV／JSON；官方下載每天更新，重跑需指定相同版本或記錄新版本。修改後執行 `npm run verify`，檢查來源 ID、不同字形數、所有分類及正確／錯誤讀音回歸。
